# The edit script of the compile-time benchmark (goal compile-time-code-rebuilds): edits a person makes while
# working on logscan, each made to both versions, the same where they share code and the
# matching one where they don't. `stilt-latency compile-time` replays it, each edit followed by
# its undoing, and times each from the files' change to the rebuilt executable.
#
# An edit starts with `edit KIND: what it does`. Each `in` line names a file of one version, and
# the runs of lines after it each replace, in that file, the text that a run of `-` lines writes,
# which the file holds once, with the text that the run of `+` lines after it writes. A `-` or a
# `+` alone stands for an empty line.
