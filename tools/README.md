# Tools

The programs that test and measure an implementation of Stilt.

| Path | Contents |
| --- | --- |
| [`runner/`](runner/) | `stilt-test`, which runs the [conformance suite](../conformance/) or the guide's examples against any implementation, compares two implementations, and reports which rules the tests cover; after each command on a directory program, and each `test`, which starts an engine for a program of one file too, it asks the implementation to stop the program's engine (`engine --stop`), so that no engine outlives the test |
| [`generator/`](generator/) | `stilt-gen`, which generates programs: well-typed ones the interpreter runs, with tests, doc examples and properties, three in ten using fixed-size arrays, value parameters and `comptime`, three in ten reflecting on values, three in ten using the procedural macros of a module of their own, as directory programs, three in ten declaring effects and handling them, one in five viewing the fields of records, one in five using text beyond ASCII, three in a hundred recursing tens of thousands of calls deep and building lists of a hundred thousand elements, three in ten declaring a trait with impls and generic functions bounded by it, one in ten whose arithmetic may overflow or divide by zero and panic, half of them ending their `main` with calls of `std.par`, ones with planted mistakes, some of them in macros, bodies that stress inference, syntax errors, and the 50K- and 100K-line projects; `stilt/` holds its scale mode written in Stilt, which writes those projects byte for byte as it does |
| [`grammar/`](grammar/) | `stilt-grammar`, which generates the grammar of `reference/03-syntax.md` as GBNF and as llguidance's Lark-like format, and checks that each keeps every prefix of the programs of the language viable, and writes the tables of words and tokens of both lexers and the editors' grammars from `reference/02-lexical.md`; `stilt/` holds its `generate` written in Stilt, which writes the two forms byte for byte as it does |
| [`registry/`](registry/) | `stilt-registry`, which generates what follows from the registry of diagnostic codes, `reference/errors.toml`: the codes of the compiler and of the reference interpreter, the language server's links to the error index, the list of codes that the coverage report expects, and the error index of `docs/errors/`, a page per code with its examples and the renderings of its snapshots; with `--check`, it fails if any of them isn't current |
| [`latency/`](latency/) | `stilt-latency`, the latency harness, which replays an edit script against a warm query database, timing each edit, splitting its time into validation, analysis, code generation and patching, and comparing it with a clean check, and against a program held in an image, comparing its code after each edit with what walking and counting the program afresh gives, times each body of a program, measures the memory of an engine that holds a project across replays of the script, replays the script through the language server, as an editor sends it, times the answers of a session of the REPL, and replays the compile-time benchmark's edit script on the benchmark and its baseline, timing each rebuild of their executables |
| [`meter/`](meter/) | `stilt-meter`, a library that reads what a process costs: the instructions it retires, the cycles it runs and its CPU time, for a running process or an ended child, so that the benchmarks and the latency harness judge their goals on what the work costs rather than on the wall time that other processes change |
| [`fuzz/`](fuzz/) | `cargo fuzz` targets for the parser, the formatter, the checks and the language server, each of which must take any bytes without panicking; the language server's, any session of an editor's, answered by a backend that gives offsets past the end or inside a character |
| [`linux/`](linux/) | The Linux machine of `just sanitizers`, which runs the compiler built with AddressSanitizer and LeakSanitizer, and of `just debuggers`, which runs the debugger tests with gdb |
| [`docker/`](docker/) | The Dockerfile of an image of a release, which installs it through `install.sh` |
| [`release/`](release/) | `notes.py`, which collects the release notes from the change files of [`changes/`](../changes/); `homebrew.py` and `nix.py`, which write the Homebrew formula and the Nix expression from `SHA256SUMS`; and `sbom.py`, which writes the release's software bill of materials in SPDX |
| [`measurements/`](measurements/) | Studies cited by the design documents, each with the script that reproduces it |

The `justfile` at the root gives the commands that run them.
