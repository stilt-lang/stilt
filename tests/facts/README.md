# Facts suite

Programs whose inferred facts are known from the records, which `stilt show` must print ([Goals](../../docs/design/goals.md), `shown-facts`). Each line that causes a fact of its function carries the fact, derived from the records by reasoning, never by running an implementation:

- the parameters each function consumes, and the calls at which it loses reuse, because it passes a place to a consumed parameter and uses the place after the call or passes it to the call twice, or passes an `inout` parameter that goes back to the caller as it was, which a path from the call takes to a return or a raise without assigning all of it; a path that panics ends the process, and takes nothing back ([values.consumed-parameters](../../reference/05-values.md#values.consumed-parameters) and [values.inout-arguments](../../reference/05-values.md#values.inout-arguments));
- the lines where it can panic, where it can overflow and where it allocates ([facts.inference](../../reference/15-facts.md#facts.inference), [facts.allocation](../../reference/15-facts.md#facts.allocation) and [facts.without-alloc](../../reference/15-facts.md#facts.without-alloc); [effects.panic-kinds](../../reference/12-effects.md#effects.panic-kinds) and [effects.panicking-operations](../../reference/12-effects.md#effects.panicking-operations)), an array's elements stored inline ([generics.array-effects](../../reference/07-types.md#generics.array-effects)), and the lines where an index, a division or a map key is proved not to panic by a rule of acceptance ([facts.range-loops](../../reference/15-facts.md#facts.range-loops), [facts.guards](../../reference/15-facts.md#facts.guards) and [facts.divisors](../../reference/15-facts.md#facts.divisors));
- its module's tier ([program.module-tier](../../reference/04-programs.md#program.module-tier));
- the modes of its locals, closure literals and parameters: where a local escapes, where a `var` is written while shared, and which closures and parameters run at most once ([modes.escaping](../../reference/13-modes.md#modes.escaping), [modes.not-escaping](../../reference/13-modes.md#modes.not-escaping), [modes.copy-on-write-types](../../reference/13-modes.md#modes.copy-on-write-types), [modes.copies](../../reference/13-modes.md#modes.copies), [modes.shared-writes](../../reference/13-modes.md#modes.shared-writes), [modes.once-closures](../../reference/13-modes.md#modes.once-closures), [modes.once-parameters](../../reference/13-modes.md#modes.once-parameters) and [modes.show](../../reference/13-modes.md#modes.show));
- the lines where it may not end and where it copies shared data, and the parameters it updates in place under `without alloc` ([facts.own-storage](../../reference/15-facts.md#facts.own-storage), [facts.writes-in-place](../../reference/15-facts.md#facts.writes-in-place) and [facts.in-place-parameters](../../reference/15-facts.md#facts.in-place-parameters); [facts.counting-loops](../../reference/15-facts.md#facts.counting-loops) and [facts.shrinking-recursion](../../reference/15-facts.md#facts.shrinking-recursion));
- the lines that give it each capability below `io` ([facts.capabilities](../../reference/15-facts.md#facts.capabilities) and [facts.capability-natives](../../reference/15-facts.md#facts.capability-natives));
- the lines where it holds shared values ([shared.locks](../../reference/14-tasks.md#shared.locks));
- the lines where reference counts may become atomic ([par.atomic-sites](../../reference/14-tasks.md#par.atomic-sites));
- the type parameters each function reflects on ([meta.reflects](../../reference/16-meta.md#meta.reflects));
- the `unsafe` blocks of each function's own code and the foreign functions it names ([c.unsafe-and-foreign](../../reference/20-builds.md#c.unsafe-and-foreign));
- and, at a declared type's first line, the fields and variants through which it can form a cycle ([cycles.can-form-cycle](../../reference/14-tasks.md#cycles.can-form-cycle)).

A program is a `.lt` file, or a directory that holds one, as in the conformance suite.

## Annotations

The expected facts are annotations in the form of the conformance suite's ([conformance.annotations](../../reference/01-conformance.md#conformance.annotations) and [conformance.inline-annotations](../../reference/01-conformance.md#conformance.inline-annotations)), so each sits beside the line it describes.

| Annotation | Expects |
| --- | --- |
| `//~ tier: core`, in a file's header region | The module's tier: `advanced` for a module that names a view type ([views.std-view](../../reference/13-modes.md#views.std-view)), declares or calls a projection ([projections.declaring-projection](../../reference/13-modes.md#projections.declaring-projection)), declares a trait with parameters, a trait function without `self`, a trait constant or a constructor trait, writes an impl of one or names one in a bound ([traits.advanced-tier](../../reference/11-traits.md#traits.advanced-tier)), writes a polymorphic function type or names `Lazy` ([polymorphism.advanced-tier](../../reference/07-types.md#polymorphism.advanced-tier) and [polymorphism.lazy-values](../../reference/07-types.md#polymorphism.lazy-values)), writes an anonymous record type, literal or pattern, a record bound, an open record type or an update of an anonymous or bounded record ([records.advanced-tier](../../reference/07-types.md#records.advanced-tier)), declares a pack ([variadics.advanced-tier](../../reference/07-types.md#variadics.advanced-tier)), declares a macro, while a module that only uses one stays in its tier, or declares an effect, writes one or `async` in a row or a type, writes a handler or `with`, performs an operation or names `std.task` ([handlers.advanced-tier](../../reference/12-effects.md#handlers.advanced-tier); [tasks.advanced-tier](../../reference/14-tasks.md#tasks.advanced-tier)), or writes `when` or names `std.sync` ([tasks.advanced-tier](../../reference/14-tasks.md#tasks.advanced-tier)), while a module that names `std.par` stays in its tier ([par.core-tier](../../reference/14-tasks.md#par.core-tier)) ([macros.advanced-tier](../../reference/16-meta.md#macros.advanced-tier)); `meta` for a module that declares a value parameter ([generics.meta-tier](../../reference/07-types.md#generics.meta-tier)), writes `comptime` ([meta.staging-tier](../../reference/16-meta.md#meta.staging-tier)), names `std.meta` or writes a bound test ([meta.reflection-tier](../../reference/16-meta.md#meta.reflection-tier)), while a module that only names a type with value arguments, uses a function with value parameters or calls a function that reflects stays in its tier; `systems` for a module that declares a foreign function, writes an `unsafe` block or names `std.c` with `use`, while a module that only calls `with_ptr`, `with_mut_ptr` or `with_c_str` stays in its tier ([c.systems-tier](../../reference/20-builds.md#c.systems-tier)) |
| `CONSUMES xs`, at the end of a line | The line's function consumes its parameter `xs` there: it returns it, stores it in a value, rebinds it with `var`, or passes it to a parameter that its callee consumes; or, at the `match` or `if let` on it that takes it apart to build in its place, an arm of which matches a variant of its recursive type with a payload and builds one |
| `LOST-REUSE xs`, at the end of a line | A call on the line consumes the place `xs`, a variable or a field of one, which the line's function uses after the call or passes to it twice, or which is an `inout` parameter that it gives back to its caller unassigned, so the callee can't reuse its memory |
| `PANIC`, at the end of a line | An operation on the line can panic, itself or through a function it names |
| `OVERFLOW`, at the end of a line | An operation on the line can overflow, itself or through a function it names: integer `+`, `-` or `*` or a compound assignment of one, `-` on a value that isn't a literal, signed `/` or `%` whose divisor isn't a literal other than `-1`, a shift whose amount isn't a literal below the width, or a call of an integer type's `abs`, `pow`, `gcd`, `lcm`, `div_euclid` or `rem_euclid` that [effects.panicking-operations](../../reference/12-effects.md#effects.panicking-operations) counts ([effects.panicking-operations](../../reference/12-effects.md#effects.panicking-operations)) |
| `PROVED bounds`, `PROVED divide-by-zero` or `PROVED missing-key`, at the end of a line | An index, a division or a read of a map's key on the line, which would panic with that kind, is proved not to by a range loop, a guard, a divisor or a key, so it adds no `panic` ([facts.range-loops](../../reference/15-facts.md#facts.range-loops), [facts.guards](../../reference/15-facts.md#facts.guards) and [facts.divisors](../../reference/15-facts.md#facts.divisors)); a line that also holds an operation that can panic carries `PANIC` too |
| `ALLOC`, at the end of a line | An operation on the line allocates, itself or through a function it names, a copy at a call for an in-place parameter among them ([facts.copy-at-call](../../reference/15-facts.md#facts.copy-at-call)) |
| `DIV`, at the end of a line | An operation on the line may not end, itself or through a function it names: a `while` that isn't a counting loop ([facts.counting-loops](../../reference/15-facts.md#facts.counting-loops)) or a `loop`, a call through a function value that a field, a local or an `escaping` parameter holds, a performance of an effect's operation ([handlers.implicit-effects-and-capabilities](../../reference/12-effects.md#handlers.implicit-effects-and-capabilities)), a call of `std.task.spawn` ([tasks.implicit-effects-and-capabilities](../../reference/14-tasks.md#tasks.implicit-effects-and-capabilities)) or of `Scope.spawn` ([tasks.implicit-effects-and-capabilities](../../reference/14-tasks.md#tasks.implicit-effects-and-capabilities)), or a call into the function's recursive group, but for a call of itself on a strict part of one parameter at every such call ([facts.div](../../reference/15-facts.md#facts.div) and [facts.descending-self-calls](../../reference/15-facts.md#facts.descending-self-calls)), or shrinking on integers at every such call ([facts.shrinking-recursion](../../reference/15-facts.md#facts.shrinking-recursion)) |
| `LOCKS`, at the end of a line | An operation on the line holds shared values, itself or through a function it names: a `when`, a call of a function that has `locks`, or such a function named as a value, a closure literal's body counting as its writer's; a call through a function value adds none ([shared.locks](../../reference/14-tasks.md#shared.locks)) |
| `ATOMIC`, at the end of a line | An operation on the line may make reference counts atomic: a call of `par.map`, `par.each`, `par.fold` or `par.both`, a call of `Shared.new`, a `when`, or a call of `task.spawn` or `s.spawn` given a closure literal that captures a value whose type holds a `Task<T>` or a function type, or given any other function value, a closure literal's counting as its writer's; a call of a function that has one adds none ([par.atomic-sites](../../reference/14-tasks.md#par.atomic-sites)) |
| `COPY`, at the end of a line | An operation on the line copies shared data, itself or through a function it names: a write that `SHARED` marks, or a copy at a call for an in-place parameter ([facts.copy](../../reference/15-facts.md#facts.copy)) |
| `FS`, `NET`, `CLOCK`, `ENV`, `CONSOLE`, `RAND`, `SPAWN` or `EXEC`, at the end of a line | An operation on the line gives its function the capability `fs`, `net`, `clock`, `env`, `console`, `rand`, `spawn` or `exec`: it calls or names a native that has it, `print`, `eprint` and `std.io`'s console functions for `console`, the natives of `std.fs` for `fs`, of `std.clock` for `clock`, of `std.cli` for `env`, `random.entropy` for `rand`, `std.task.spawn` and `Scope.spawn` for `spawn`, the natives of `std.net` for `net` and those of `std.process` for `exec` ([tasks.implicit-effects-and-capabilities](../../reference/14-tasks.md#tasks.implicit-effects-and-capabilities)), or a function that has it, itself or through a closure literal it contains; a call through a function value gives none, and neither does `exit` ([facts.capabilities](../../reference/15-facts.md#facts.capabilities), [facts.capability-natives](../../reference/15-facts.md#facts.capability-natives) and [facts.calls-through-function-values](../../reference/15-facts.md#facts.calls-through-function-values)) |
| `IN-PLACE xs`, at the end of a line | The line makes the parameter `xs` of a function limited by `without alloc` in place: it writes the parameter's storage in place, or passes it on to an in-place parameter ([facts.in-place-parameters](../../reference/15-facts.md#facts.in-place-parameters)) |
| `ESCAPES x`, at the end of a line | The local or closure binding `x` escapes the function there: the line returns it, raises it, stores it in a value, assigns it to an `inout` parameter, into a part of another value or through an index, captures it in a closure that escapes, or passes it to a consumed parameter ([modes.escaping](../../reference/13-modes.md#modes.escaping)) |
| `SHARED x`, at the end of a line | The line modifies the `var` or `inout` parameter `x`, or a part of it, while a copy of the part may still last ([modes.shared-writes](../../reference/13-modes.md#modes.shared-writes)) |
| `VIEWS x`, at the end of a line | The view bound on the line, or the result returned there, reads the source `x` ([views.show](../../reference/13-modes.md#views.show)); the word stands for `fixed` |
| `WRITES x`, at the end of a line | The writable binding made on the line writes the source `x` ([projections.writable-modes](../../reference/13-modes.md#projections.writable-modes) and [projections.show](../../reference/13-modes.md#projections.show)); the word stands for `fixed` |
| `REFLECTS T`, at the end of a function's first line | The function reflects on its type parameter `T`: its body names `T.shape()`, or gives `T` to a type parameter of a function that reflects on it ([meta.reflects](../../reference/16-meta.md#meta.reflects)) |
| `ONCE f`, at the end of a line | The closure bound to `f` on the line, or the parameter `f` at its one use on the line, runs at most once ([modes.once-closures](../../reference/13-modes.md#modes.once-closures) and [modes.once-parameters](../../reference/13-modes.md#modes.once-parameters)); `ONCE` alone marks an unbound closure literal |
| `UNSAFE`, at the end of a line | The line holds the `unsafe` of an `unsafe because` block of the line's function's own code, a closure literal's body included; a caller of the function has none ([c.unsafe-and-foreign](../../reference/20-builds.md#c.unsafe-and-foreign)) |
| `FOREIGN f`, at the end of a line | The line calls the foreign function `f`, or names it as a value; a foreign call adds no implicit effect, while `with_c_str` panics and allocates, `with_mut_ptr` allocates and `with_ptr` does neither ([c.effects](../../reference/20-builds.md#c.effects), [c.lending-buffer](../../reference/20-builds.md#c.lending-buffer) and [c.unsafe-and-foreign](../../reference/20-builds.md#c.unsafe-and-foreign)) |
| `CYCLE f`, at the end of a type's first line | The type can form a cycle through its field or variant `f`: its type holds a `Shared<U>` whose `U` holds that same `Shared<U>`, a function or handler type, a type parameter or a pack, or a `Lazy<T>` ([cycles.can-form-cycle](../../reference/14-tasks.md#cycles.can-form-cycle)); one annotation for each such field or variant |

One annotation may hold several entries, as in `//~ CONSUMES xs LOST-REUSE xs ALLOC`. A line that causes a fact several times, as two list literals do, is marked once.

## What is checked

`just facts`, part of `just test`, runs `stilt show --json` on each module of each program, and checks that the facts it shows are exactly those the annotations expect, at the same lines, and that the module's tier is the one its header expects. It is part of `just ci`.
