The VS Code extension finds `stilt` in `~/.stilt/bin`, `$STILT_HOME/bin`, Homebrew's and Nix's directories and your login shell's `PATH`, so the language server starts when VS Code was opened from the Dock or a desktop menu, which failed before with `spawn stilt ENOENT`. Without Stilt, one notification offers to install it with `install.sh` or to locate it, and the server starts once it is installed, with no reload; an outdated `stilt` is offered an update. The language status shows the version and the server's state and opens a menu of actions, and the extension adds **Stilt: New Project…**, a walkthrough, and the settings `stilt.env`, `stilt.server.enable`, `stilt.installPrompt`, `stilt.codeLens.run`, `stilt.codeLens.debug` and `stilt.run.arguments`. `stilt.path` is now empty by default, and accepts `~` and `${workspaceFolder}`.
