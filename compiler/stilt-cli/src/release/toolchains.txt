# The release toolchains that this version of `stilt` names (builds.fetching-toolchain): for each host,
# the URL of its archive and the SHA-256 of the archive's bytes, one host to a line, as
#
#     aarch64-macos https://…/clang-22.1.8-aarch64-macos.tar.gz 5f1c…
#
# An archive is a gzip-compressed POSIX tar that holds `bin/clang` and whatever it loads,
# written by `stilt_pkg::toolchain::archive::pack`, and publishing one adds its line here.
# A host without a line builds release builds with the toolchain's own clang or `STILT_CC`.
# Each archive repacks the `bin/clang-22` of LLVM's own release binaries, unchanged. Not 23.x: LLVM
# 23.1.0 to 23.1.5 fold `0.0f * (0.0f / d)` to `0.0f` when `d` comes out of a loop and may be zero.
