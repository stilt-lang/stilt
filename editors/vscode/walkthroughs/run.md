# Run, test and debug

- **Run** above `main`, or the run button of the editor's title, runs `stilt run` in a terminal, which takes each edit in while the program runs.
- **Debug** builds the program and runs it under LLDB DAP or CodeLLDB, with the breakpoints set in its `.lt` files.
- The **Test Explorer** lists each `test "name"`, each doc example and each property, and runs them with `stilt test`.
- **Tasks: Run Task** offers `check`, `build`, `test`, `run` and `fmt` for each program.

Files format on save with `stilt fmt`'s formatter.
